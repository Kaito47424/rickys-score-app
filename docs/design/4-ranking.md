# 4-4: ランキング表示

## 概要
メンバーが「俺今何位？」をすぐ確認できるランキング画面。今季固定ではなく
年度切り替え可能（個人成績画面と同じ年度フィルタ）。

## 表示内容（各上位5件、規定未達は除外）
- 打率ランキング（規定打席以上を対象）
- 本塁打ランキング（しきい値なし）
- 防御率ランキング（投球回3以上を対象）
- OPSランキング（規定打席以上を対象）

規定打席 = チーム試合数 × 2.1（`app/src/utils/qualification.ts`）。個人成績画面
（`app/src/components/Stats/index.tsx`）の規定打席判定と同じロジックを共有し、
しきい値が食い違わないようにしている。投手の規定投球回は導入していないため、
防御率ランキングのみ独自の「投球回3以上」というシンプルなしきい値を使用する。

## 使用データ
`getBatStats`/`getPitchStats`（年度パラメータ指定）・`getGames`（チーム試合数算出用）
既存APIのみで実装済み。追加GAS実装なし。

## URL
`/view/ranking`

`app/src/components/Ranking/index.tsx`
